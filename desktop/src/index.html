Native Desktop Installers (Mac DMG, Windows EXE & Linux AppImage)

macOS DMG Disk Image

Apple Silicon (M1/M2/M3) & Intel x64

Packages the launcher into an Apple standard .dmg disk image with drag-and-drop to /Applications, custom app icon, and retina background.

Format .dmg (Disk Image) & .zip
Build Command npm run build:mac
Output Folder desktop/dist/
⊞

Windows Installer & Portable EXE

Windows 10 / 11 (64-bit)

Generates an NSIS setup wizard .exe with desktop shortcut, Start Menu entry, and a standalone portable .exe that runs without installation.

Format .exe (NSIS Installer & Portable)
Build Command npm run build:win
Output Folder desktop/dist/
🐧

Linux AppImage & DEB

Universal Linux (Ubuntu, Debian, Fedora, Arch)

Packages into a self-contained portable .AppImage that runs on all Linux distributions, along with a Debian .deb package for apt.

Format .AppImage, .deb & .tar.gz
Build Command npm run build:linux
Output Folder desktop/dist/

Continuous GitHub Actions Automated Releases

Whenever you push a git tag (e.g., v1.0.0), GitHub Actions automatically compiles macOS .dmg, Windows .exe, and Linux .AppImage on cloud runners and publishes a GitHub Release for your users!

git tag v1.0.0 && git push origin v1.0.0
